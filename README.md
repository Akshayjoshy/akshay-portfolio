# Akshay Joshy — Portfolio

Next.js (App Router), TypeScript, Tailwind CSS, Motion, Lucide.

## Getting started

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
npm run start
```

## Environment

Copy `.env.example` to `.env.local` and set `NEXT_PUBLIC_SITE_URL`.

## Content

Edit `data/*.ts`. Add your resume at `public/resume/Akshay-Joshy-CV.pdf` and an OG image at `public/og/og-image.png`.

## Deploy

Push to GitHub, import the repo in Vercel; `main` deploys automatically.
